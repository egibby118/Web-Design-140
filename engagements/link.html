Questions

  1. What is the difference between absolute and relative links? Why would you use relative links?

    2. Absolute links require all parts of the URL (protocol, domain, and path), while relative links are usually within your folders, so they only require the domain and path. Absolute links usually link to entirely seperate websites, while relative ones link to sites that are related to your main website. Relative links make linking to related sites easier than absolute links, and cause less bugs when uploading to the internet.

  2. List the three rules with relative links.

    3. Three rules: If they're siblings, just use the file name. If it's a child relationship (folder within the main folder), anchor link type the name of the folder slash the name of the file. It it's an aunt/uncle, type two periods slash your file name.

  3. Do links always need to be inside a NAV tag?

    4. No, they can be all over the websites. But it is recommended that you organize your links properly so that people can traverse your webiste easier. That is what the NAV tag is for.

One period represents the current folder, two periods represents the parent folder (up a folder).

Things and Stuff

List out the different ways to select an item.

You can type out the tag name, select it as a decendent of a bigger tag, use and ID, give it a class and select that class, use a SPAN or DIV tag.

What is the difference between an ID and a Class?

IDs are unique to each tag and cannot be used again on a different tag. Classes can be reused for several different tags. IDs should be used sparingly, classes should be the go to. They can be used together at the same time

What is the difference between a SPAN tag and a DIV tag?

SPAN tags selects text without causing line breaks, while DIV tags cause line breaks before and after the selected text.

What is the difference between a DIV tag and a HEADER, MAIN, or FOOTER?

They seperate the different areas of code within the terminal, but otherwise they function the same.

What are the different ways to select a color?

You can select from the list of predefined names CSS provides you or you can use RGB codes to get your exact desired color.

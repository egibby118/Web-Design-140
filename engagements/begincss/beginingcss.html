Explain the difference between inline, embedded, and external CSS.

Inline is the second in line in the CSS cascading hierarchy, embedded is having the style tags inside the html code, and external is when style tags have their own CSS page separate from the HTML page but still connected.

Explain why you should only use external CSS.

So that any graphic designers that you have working on the look of the page can access and change it easily while not disturbing the code.

What is a selector used for?

The selector makes it easy to pick what you want to modify on certain tags and can give you an easy list to choose from.

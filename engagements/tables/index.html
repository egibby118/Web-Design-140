Why don't we use the border attribute?

Because it's outdated and using CSS is easier and makes the HTML code less cluttered.

What is the easiest way to color every other row a different color?

Use the tag tbody tr:nth-child(even/odd)

What does the value in the parentheses of your structural pseudo-class mean? Give one other value you could use and which rows it would select.

The word in the parentheses tells your CSS what rows to change. You could make it even to change rows 2,4,6,8,etc. You could use odd to change rows 1,3,5,6,etc.

The form tag has an "action" attribute. What does it do?

The action is what type of form you display.

The form tag has a "method" attribute. What does it do?

The method declares whether you are doing a Post or Get request.

What is the difference between a "POST" and a "GET"?

Post sends the inputted info more securely while Get puts the inputs in the URL on the next page. Post can change thw website while Get simply retrieves the info without changing things.

How do you fill in a form control with a pre-set value, and how is that different from a placeholder? Answer for each of these: text box, textarea, select box, checkbox, and radio button.

Text box- type in the text box. select box- select one of the options. checkbox- check one or more of the boxes. radio button- select one or more of the buttons.

Why is the viewport meta tag important?

The viewport meta tag allows people on mobile devices to be able to view your website as easily as someone on a computer.

How can you adjust the CSS for printing?

You can use the meadia tag in your CSS file and adjust your page there for printing while to normal website remains unchanged

When would you want to adjust the CSS for printing?

You would adjust it for links and unecessary colors.

When you select the same tag twice, and in one of them you say "flex-direction: column;" and the other says "flex-direction: row;", which one takes priority?

The flex-direction: row;.

How do you change the CSS for a web page displayed on a phone?

In CSS you type in the tag @media ONLY screen AND (max-width: x px) and edit your site for mobile from there.

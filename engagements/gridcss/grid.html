According to the instructor, what is the main difference between CSS Grid and CSS Flex?

Grid CSS is two dementional and determines everything about the child tags. Flex CSS is more lenient and lets the child tags determine how big they should be and the parent tags will listen.

Who decides where a child goes on the page: the child or its parent? Explain using your three-column layout.

The parent decides where the child should go on the page. With the three column layout I made, the div tag with the parent class tells the div tags with the card class to have a gap of 15px and that their boxes should be 1fr wide each, and the child boxes listen and are layed out in that exact fashion.

Internet

Web

The Web is the way that computers can talk to each other.

How are they different?

They are different because the Internet is comprised of computers that are connected to each other, but have no way of communicating. The Web is the way that computers are able to communicate.

ASCII and Unicode

ASCII is a character code where each set of numbers of symbols represents a unique character. Unicode is a character code that uses a unique number for every single charcter no matter the language.

What is UTF-8

It is the latest and most widely used Unicode system.

URL

It is the unique address that is used to find web pages and other files on the internet.

Domain name

The readable address that you use to differentiate and find web pages.

HTTP

The rules that web pages follow to be able to submit and read data.

HTTPS

The more secure and encrypted version of HTTP

IP Adress

The numerical code that is unique and assigned to every device that is connected to the internet like computers and phones.

DNS

Translates each web site's name into an IP address that can be read by machines.

W3C Recommendations

The web standards that keep the web running smoothly.

HTML

HTML is the most common coding language used across the web. XML is a similar language but is specifically used to store and transport data. XHTML is strciter and is based more around XML than HTML. HTML5 is the latest and most commonly used version of HTML currently.
